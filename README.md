## ⚙️ How It Works

Every chatbot in this portfolio follows the same clean architecture:

```javascript
// The entire bot is configurable from one CONFIG block
const CONFIG = {
  botName: "Driftly Support",
  primaryColor: "#6366f1",
  groqApiKey: "YOUR_KEY_HERE",
  systemPrompt: `You are a helpful assistant for Driftly...`,
  suggestions: ["Pricing plans", "How do I cancel?", "Contact support"]
};
```

**To customize for a client:**
1. Change `botName`, colors, and logo
2. Update `systemPrompt` with the client's business info
3. Add their FAQs to the knowledge base
4. Deploy — done ✅

No backend. No server. No database. Just one HTML file.

## 📦 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/KumailH12/ai-chatbot-portfolio.git

# 2. Navigate to any bot
cd ai-chatbot-portfolio/faq-bots/driftly

# 3. Open in browser (use Live Server in VS Code for best results)
# Or just double-click index.html
```

> ⚠️ You'll need a [Groq API key](https://console.groq.com) (free tier available).  
> Add it to the `CONFIG.groqApiKey` field inside the HTML file.
